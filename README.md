# Сайт "ЛУЧ" — Студия автосвета

## 📋 Задача

Создать современный сайт для студии автосвета "ЛУЧ" с акцентом на фирменный стиль и логотип.

---

## 🎨 Дизайн-концепция

### Основа:
- **Чёрный фон** (#000000)
- **Белый неоновый текст** (#FFFFFF с эффектом glow)
- **Логотип "ЛУЧ"** — центральный элемент дизайна
- **Минимализм** — чистый, технологичный стиль

### Цветовая палитра:
```css
--primary-bg: #000000;
--primary-text: #FFFFFF;
--accent-blue: #00D9FF;
--accent-purple: #B026FF;
--secondary-bg: #1A1A1A;
```

---

## 📐 Структура сайта

### Главная страница:
1. **Hero-секция:**
   - Логотип "ЛУЧ" крупно по центру
   - Анимация свечения (glow effect)
   - Краткий слоган: "Студия профессионального автосвета"
   - CTA-кнопка: "Записаться на установку"

2. **Услуги:**
   - Установка LED фар
   - Ретрофит Matrix LED
   - Лазерный свет
   - Адаптивные системы освещения
   - Ремонт и диагностика

3. **Портфолио / Работы:**
   - Галерея фото автомобилей
   - До/После
   - Акцент на качество света

4. **О студии:**
   - Кто мы
   - Почему мы
   - Технологии

5. **Контакты:**
   - Адрес (Москва, Тюменский проезд)
   - Телефон
   - Форма записи

---

## 🛠️ Технологии

### Стек (предложение):
- **HTML5 / CSS3 / JavaScript** (чистый код)
- **Анимации:** GSAP или CSS animations
- **Эффекты:** Glow/neon эффекты на CSS
- **Адаптив:** Mobile-first подход
- **Оптимизация:** Lazy loading для изображений

### Альтернатива (если нужен фреймворк):
- **Next.js** (для SEO и скорости)
- **Tailwind CSS** (для быстрой стилизации)
